# Product plan

## Current milestone

- Persistent transparent desktop creature
- Original idle, walk, blink, happy, look, reach, and tap frames
- Pointer awareness, alpha-aware click-through, click, drag, roaming, and work-area bounds
- Autonomous offline behavior and desktop/room transitions
- Independent room window and development state panel
- Versioned local persistence

## Next milestone

Add explicit quiet-presence and interaction-cooldown policies, a compact ignorable three-choice bubble, and deterministic mock dialogue. Keep all prompting local and optional before introducing any AI provider.

## Later

- Opt-in minimal activity awareness
- Provider interfaces for Groq and Notion/CourseAI
- Memory extraction with retention controls
- New style-matched room, prop, sleep, sit, play, and doodle sprites
- Packaging, startup preference, and auto-update work
